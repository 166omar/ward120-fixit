# Fix Ward 120 Implementation Plan

> **For agentic workers:** Executed in-session (no subagents — owner delegated an autonomous single-agent build). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a tested, live community fault-reporting site for Ward 120 (water leaks + rural roads) with a public trust ledger and a Truth and Solidarity admin console.

**Architecture:** Static two-page site (public + admin) on GitHub Pages calling a dedicated Supabase project (`vzwkelixolmexgfkwoif`) directly with the anon key; RLS + column grants enforce all security; Leaflet/OSM for maps.

**Tech Stack:** Vanilla HTML/CSS/JS, Leaflet 1.9.4 (cdnjs), @supabase/supabase-js v2 (jsdelivr UMD), Supabase (Postgres/Auth/Storage), Playwright MCP for E2E, GitHub Pages.

**Note on plan granularity:** Full UI code lives in the source files, not duplicated here; this plan pins the contracts — schema SQL, security grants, config shape, page responsibilities, exact test steps and expected results.

## Chunk 1: Database + security

### Task 1: Schema migration
**Files:** Create `supabase/migrations/001_schema.sql` (record of what was applied via MCP `apply_migration`)

- [ ] Seed `admin_emails` with `166omar@gmail.com`; seed confirmed auth user + identity with bcrypt password (temp password recorded in README).

### Task 2: Prove security in SQL
- [ ] `set local role anon; select reporter_phone from reports;` → **must error** (permission denied).
- [ ] `set local role anon; update reports …` → **must affect 0 rows / deny**.
- [ ] `set local role anon; insert (citizen cols) returning ref` → **must succeed**, ref = `W120-0001`, status defaults `new`, history row auto-created.
- [ ] `set local role anon; delete` → **must deny**. Then remove test row as postgres.
